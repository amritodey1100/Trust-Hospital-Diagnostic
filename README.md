# Trust Hospital & Diagnostic

A modern, responsive website for **Trust Hospital & Diagnostic (ট্রাস্ট হসপিটাল & ডায়াগনষ্টিক)** - a 24/7 diagnostic center located in Narayanganj, Bangladesh.

![Trust Hospital](assets/images/hero-bg.png)

## 🏥 About

Trust Hospital & Diagnostic provides world-class diagnostic services including:

- Digital X-Ray
- 4D Ultrasonography
- Pathology Lab
- ECG & Echo
- Physiotherapy
- 24/7 Pharmacy

**Location:** Doric Madani Tower (10th Floor), Chittagong Road, Narayanganj  
**Phone:** 01718-614888  
**Hours:** Open 24 Hours / 7 Days

## ✨ Features

- **Fully Responsive** - Works on all devices (mobile, tablet, desktop)
- **Modern Design** - Premium medical aesthetic with blue/teal color palette
- **Smooth Animations** - Fade-in effects, hover animations, counter animations
- **SEO Optimized** - Proper meta tags and semantic HTML5
- **Accessibility** - ARIA labels and keyboard navigation support
- **Fast Loading** - Optimized images and lazy loading

## 🛠️ Technologies Used

- HTML5
- CSS3 (Flexbox, Grid, Custom Properties)
- Vanilla JavaScript
- Google Fonts (Poppins)
- Font Awesome Icons
